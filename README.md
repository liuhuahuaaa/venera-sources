# venera-sources

个人收集 / 自制的 Venera 漫画源列表。共 42 个源。

## 在 Venera 里添加

漫画源 → URL，填下面任意一个（推荐第一个，本机实测可通）：

| 线路 | URL |
|---|---|
| gh-proxy 镜像（推荐） | `https://gh-proxy.com/https://raw.githubusercontent.com/liuhuahuaaa/venera-sources/main/index.json` |
| jsDelivr | `https://cdn.jsdelivr.net/gh/liuhuahuaaa/venera-sources@main/index.json` |
| GitHub raw 直连 | `https://raw.githubusercontent.com/liuhuahuaaa/venera-sources/main/index.json` |

然后在列表里勾选要装的源。

## 说明

- `sources/dongman_la.js`：动漫啦源，自写，key=`dongman_la_v3`，实测 64 项断言全过。
- `description` 里写着「站点近期实测不可达」的源（爱看漫、漫网、旧版动漫啦）属于站点本身挂了。
- 其余源来自公开的 venera-configs 社区仓库与网友修复版，版权归原作者；本仓库只做聚合，方便自己在手机上一次装完。
- 三套 index 只是把源文件地址换个线路，内容相同；哪条能通就用哪条。
